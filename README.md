## 内容介绍

### 1.从塔底出发

为了尽可能的减少因为牌库过大而导致的牌组构筑困难，我们在鸡煲的选人界面添加了一个开关，当你启用“数据扩展”时，本模组的内容在这局游戏才会生效。

在多人游戏中，内容的启用将会跟随主机设置。

出发时，鸡煲将额外携带一件遗物：扩容磁盘（战斗结束的卡牌奖励中将额外包含一张牌）。

> [!NOTE]
>
> 在公开预览版本发布之前，“扩容磁盘”等部分遗物将暂时使用原版的素材。

### 2.即将遇到的新机制

#### 2.1 过热

”过热“是一种**同时具有风险与收益**的**状态**，具体机制如下（这些能力是相互叠加的）：

1层时，获得2点瓦解；

2层时，获得1层瓦解；

3层时，获得3层瓦解；

4层时，获得状态”孤注一掷“。退出4层过热时，抽2张牌（抽牌效果可以重复触发）。

失去过热时，获得1点能量（被**[转化](#23-转化)**时，不会获得能量）。

灵活的控制自己的瓦解层数，能在战斗中衍生出更多的打法。同时，这也可以与原版鸡煲的多种体系相互配合！

#### 2.2 熔离充能球

> [!NOTE]
>
> 熔离充能球的被动与激发效果还在敲定当中，这里的内容可能**不是最新的**。

熔离充能球会让你在每回合结束时，受到1点**伤害**，并且触发所有充能球的被动1次。（锟斤铐烫烫烫！）

激发时，会触发你所有充能球的被动2次。

被动与激发效果**不受集中影响**。

#### 2.3 转化

转化是对于过热的一种特殊**关键词**，经过“转化”的过热能力不会给予你能量。

转化目前还只预留了接口，我们还没有实际使用它。

#### 2.4 衰退

衰退是一个**卡牌关键词**，目前只用在了卡牌“乱码的图标”上。

从这张卡牌上获得的能力与状态，层数下降50%。

### 3.新朋友与老朋友

我们加入了一些新的遗物与事件，在这其中你会遇到一些熟悉的面孔！

#### 3.1 被感染的旧日遗物

我们移植了5个《杀戮尖塔》的遗物，但是在移植之后……这些遗物似乎发生了**异变**？

被感染的旧日遗物虽然保有以前的强大效果，但同时也会给予你一个特殊的**诅咒**。

#### 3.2 随机事件

在前往塔顶的路上，你可能会遇到神奇的女巫小屋，听到从暗港传来的巨大异响，或是遭遇一场“抢劫”。

*“这样才对”    ——一个神秘人如此说。*

### 4.部分机制说明

#### 4.1 素材收集

素材收集的卡面描述为“将3张随机状态牌加入你的手牌”。

实际上，随机状态牌的牌池中不包括这些状态牌：呼唤、狂乱逃离、凋萎、煤灰。

#### 4.2 乱码的图标

“乱码的图标”实际实现逻辑为：将你身上所有能力（不包括临时能力，例如“热修复”）的层数除以 2，并重置成同类里的随机一项。

“随机化”实际上只会在当前角色的能力池（包含力量与敏捷的加减）中随机，选择目标不包括“热修复”一类的临时能力。

#### 4.3 D6

D6的随机遗物池仅包括这些稀有度：普通、罕见、稀有、商店。

你无法使用D6来获得初始与先古遗物。（事件遗物只能从事件获得）

#### 4.4 熔离充能球

熔离球的被动与激发效果无法由任何熔离充能球触发。
