# 鸡煲：数据扩展

欢迎来到《鸡煲：数据扩展》！

本模组为原版鸡煲的内容与玩法扩展，我们为鸡煲带来了两项新的机制（“故障”与“废料”）以及一些新的遗物与事件（遗物与事件并不只面向鸡煲！）。

*现在鸡煲终于不是尖塔第四强的角色了！*

*谁知道呢*。

> [!IMPORTANT]
>
> README文档的内容随模组的开发进度而更新，仍在施工当中。

## 内容介绍

### 1.从塔底出发

为了尽可能的减少因为牌库过大而导致的牌组构筑困难，我们在鸡煲的选人界面添加了一个开关，当你启用“数据扩展”时，本模组的内容在这局游戏才会生效。

出发时，鸡煲将额外携带一件遗物：扩容磁盘（卡牌奖励中额外包含一张牌）。

> [!NOTE]
>
> 在公开预览版本发布之前，“扩容磁盘”将暂时使用原版”数据磁盘“的遗物图标。

### 2.即将遇到的新机制

#### 2.1 故障

”故障“是一种**同时具有风险与收益**的**状态**，具体机制如下（这些能力是相互叠加的）：

2层时，失去2点力量；

4层时，获得4层瓦解、5点力量、2点敏捷；

6层时，获得4层瓦解，获得能力”机器学习“（层数为1层）；

8层时，获得2点敏捷，获得状态”孤注一掷“。

灵活的控制自己的故障层数，能在战斗中衍生出更多的打法。同时，这也可以与原版鸡煲的多种体系相互配合！

#### 2.2 废料

> [!NOTE]
>
> 目前，”废料“机制仍处于设计阶段，我们正在考虑其具体实现方法，因此这里的机制说明**可能不是最新的**。在未来，”废料“可能从额外资源系统转为其他设计方向。

”废料“为鸡煲的额外资源（类似于储君），部分卡牌能够获取废料，也可以消耗废料。”废料“机制能够与原版鸡煲的多种体系相互配合。

#### 2.3 熔离充能球

> [!CAUTION]
>
> 该机制目前未正式进入设计阶段，在这里仅作思路展示！

”熔离“充能球的被动效果能够让**有格挡**的敌人受到来自于鸡煲更多的伤害（目前设想数值为受到的伤害提升60%，每有1点集中，这项数值提升10%）。

激发充能球时，**移除**随机一名敌人的格挡，并为其施加易伤与跟踪锁定（塔一的旧机制，受到来自于充能球的伤害提升50%）。若没有敌人有格挡，则对所有敌人施加易伤与跟踪锁定。
