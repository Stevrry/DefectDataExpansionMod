# 鸡煲：数据扩展

欢迎来到《鸡煲：数据扩展》！

本模组为原版鸡煲的内容与玩法扩展，我们为鸡煲带来了多项新的机制（目前的主要机制是“过热”与“熔离”）以及一些新的遗物与事件（遗物与事件并不只面向鸡煲！）。

*现在鸡煲终于不是尖塔第四强的角色了！*

*谁知道呢*。

## 内容介绍

### 1.从塔底出发

为了尽可能的减少因为牌库过大而导致的牌组构筑困难，我们在鸡煲的选人界面添加了一个开关，当你启用“数据扩展”时，本模组的内容在这局游戏才会生效。

出发时，鸡煲将额外携带一件遗物：扩容磁盘（卡牌奖励中额外包含一张牌）。

> [!NOTE]
>
> 在公开预览版本发布之前，“扩容磁盘”将暂时使用原版”数据磁盘“的遗物图标。

### 2.即将遇到的新机制

#### 2.1 过热

”过热“是一种**同时具有风险与收益**的**状态**，具体机制如下（这些能力是相互叠加的）：

1层时，获得2点瓦解；

2层时，获得2层瓦解；

3层时，获得3层瓦解；

4层时，获得4层瓦解；

5层时，获得状态”孤注一掷“。

失去过热时，获得1点能量（被**转化**时，不会获得能量）。

灵活的控制自己的瓦解层数，能在战斗中衍生出更多的打法。同时，这也可以与原版鸡煲的多种体系相互配合！

#### 2.2 熔离充能球

> [!NOTE]
>
> 熔离充能球的被动与激发效果还在敲定当中，这里的内容**不是最新的**。

”熔离“充能球的被动效果能够让**有格挡**的敌人受到来自于鸡煲更多的伤害（目前设想数值为受到的伤害提升60%，每有1点集中，这项数值提升10%）。

激发充能球时，**移除**随机一名敌人的格挡，并为其施加易伤与跟踪锁定（塔一的旧机制，受到来自于充能球的伤害提升50%）。若没有敌人有格挡，则对所有敌人施加易伤与跟踪锁定。

#### 2.3 转化

转化是对于过热的一种特殊消耗**关键词**，经过“转化”的过热能力不会给予你能量。

转化会被用在部分卡牌上（目前的设计方向为与“熔离”绑定）。

#### 2.4 衰退

衰退是一个**卡牌关键词**，目前只用在了卡牌“乱码的图标”上。

从这张卡牌上获得的能力与状态，层数下降50%。

### 4.部分卡牌机制说明

#### 4.1 素材收集

素材收集的卡面描述为“将3张随机状态牌加入你的手牌”。

实际上，随机状态牌的牌池中不包括这些状态牌：呼唤、狂乱逃离、凋萎、煤灰。

#### 4.2 乱码的图标

“乱码的图标”实际实现逻辑为：将你身上所有能力与状态的层数除以 2，并重置成同类里的随机一项。

“随机化”实际上只会在当前能力或状态种类的池子中随机，选择目标不包括“热修复”一类的临时能力。
